MAGNEXIS · DATA RELEASE

T-Pot Evidence Lab

A small, sanitized honeypot-evidence dataset for defensive classification, evaluation, and local model workflows.

View dataset on Hugging Face Browse source on GitLab

What’s inside

  • 741 structured events across 126 opaque source groups
  • Chat, Alpaca, ShareGPT, prompt/completion, JSONL, and Parquet formats
  • Source-disjoint train, validation, and test splits
  • Local Ollama and generic Harness² evaluation bridges

Use responsibly

Labels are weak deterministic thresholds, not attribution or a basis for automatic enforcement. The public release removes literal IPs, credentials, payloads, captured commands, and local targets.
